# راهنمای استفاده از ArkaFEM Prompt Kit — نسخه 2.0

**ArkaFEM**: کتابخانه Open Source محاسبات اجزای محدود و تحلیل سازه در MATLAB. مرجع محاسباتی اصلی: Daryl L. Logan, *A First Course in the Finite Element Method*, 6th ed. هدف سازگاری: MATLAB R2024b+ (تا زمان آزمون قطعی نیست).

## از کجا شروع کنم؟
1. این بسته را **به طور کامل** به Agent توسعه‌دهنده بده. متن `00_READ_FIRST/01_MASTER_AGENT_PROMPT_FA.md` را به عنوان نخستین دستور ارسال کن. برای گفتگوهای جدید، بسته ZIP جدید تحویلی مرحله قبل و این Prompt Kit را ارسال کن.
2. پس از خواندن قراردادها، فقط `PROMPTS/01A_REPOSITORY_BOOTSTRAP.md` را اجرا کن. هر فایل در `PROMPTS` یک **واحد کاری مستقل** و مرز توقف دارد.
3. Agent پس از هر پرامپت باید **یک ZIP کامل سورس ریشه ArkaFEM** + گزارش وضعیت + فایل‌های تغییرکرده + نتیجه تست‌ها تحویل بدهد؛ سپس **متوقف شود**. تنها با دستور صریح «برو بخش بعد» ادامه یابد.
4. برای ادامه در گفتگوهای جدید: آخرین ZIP سورس معتبر، Prompt Kit، خروجی `docs/STATUS.md` و `docs/HANDOFF.md` را بده؛ Agent ابتدا وضعیت واقعی را استخراج کند، نه از حافظه حدس بزند.
5. این بسته فعلاً **نقشه راه و پرامپت** است؛ هیچ مرحله توسعه MATLAB را انجام‌شده اعلام نمی‌کند. فایل `TEMPLATES/Makefile` نمونه اولیه قرارداد Git/QA است؛ هنگام اجرای 01A باید به ریشه مخزن وارد و با اسکریپت‌های واقعی هماهنگ شود.

## فایل‌های مهم
- `CONTRACTS/PROJECT_CHARTER.md`: محدوده و هویت پروژه، ورژن‌ها، قواعد API
- `CONTRACTS/MATERIALS_AND_SECTIONS.md`: کاتالوگ مصالح/مقاطع و جزئیات SAP-like
- `CONTRACTS/NUMERICAL_AND_DOC_POLICY.md`: قواعد عددی، فرمول‌ها، benchmarkها، جلوگیری از خطا
- `CONTRACTS/DEV_GIT_QA_STATUS.md`: Git، Makefile، zip، وضعیت، کیفیت و تحویل
- `CONTRACTS/ROADMAP_PROGRESS.json`: نقشه وزن‌دار قابل ماشین‌خوانی
- `REFERENCES/*`: اسناد معماری و Numerical Contracts طراحی اولیه که باید حفظ شوند
- `TEMPLATES/Makefile`: الگوی دستورات قابل استفاده در هر ZIP سورس
- `TEMPLATES/STATUS_REPORT_TEMPLATE.md`, `TEMPLATES/DOC_FORMULA_TEMPLATE.md`: الگوی تحویل

## نکات انتشار
مجوز MIT **پیشنهاد** است و پیش از اولین انتشار عمومی باید با صاحب پروژه تأیید شود. از تکثیر مثال‌های طولانی دارای حق نشر Logan، پایگاه‌های داده تجاری مقاطع، و کد اختصاصی SAP2000 خودداری شود. مقایسه SAP2000 صرفاً روش اعتبارسنجی مستقل است، نه ادعای سازگاری API یا دقت تضمینی.
