# ArkaFEM / PROMPT 01B — Public Model Facade and Validation

**این فایل فقط یک واحد کاری است.** فقط با دستور صریح کاربر اجرا شود. مبنا: آخرین **ZIP کامل ArkaFEM** و تمامی فایل‌های `00_READ_FIRST`, `CONTRACTS`, `REFERENCES`. تاریخچه و کدهای مرحله قبل را حفظ کن. اگر ZIP ورودی موجود نیست، ادامه را از روی حدس نساز.

**در تمام مراحل الزامی:** MATLAB R2024b+ هدف سازگاری (فقط بعد از آزمون تأیید)، SI، `arka` namespace، sparse، نظام DOF، تفکیک Material/Section/Element، قرارداد عددی Logan، تست منفی، Makefile با دستورات Git، مستندسازی روابط و مثال‌ها، status دوگانه implemented/verified. هیچ کد آینده‌ای را بدون تست runnable نام نبر. قراردادهای Master Prompt را کاملاً اجرا کن.

## هدف این برش
Implement provisional `arka.Model` handle class for consistent node/material/section data records, IDs, revision mutation, query/list operations and defensive external snapshots; avoid false full analysis claims.

## تسک‌های دقیق اجرایی
1. Implement provisional `arka.Model` handle class for consistent node/material/section data records, IDs, revision mutation, query/list operations and defensive external snapshots; avoid false full analysis claims.
2. Validate 2D vs 3D coordinate length, positive integer IDs, finite values, duplicate IDs, missing material references, immutable snapshots; stable `arka:validation:*` identifiers.
3. API examples explicitly distinguish runnable operations from future `addFrame`/`solveStatic`.

## حداقل آزمون پذیرش
1. Positive and negative Model registry tests incl duplicate node, duplicate material, wrong dimensionality; version increment and snapshot isolation.
2. Stage 01 task S01.03 and S01.04 evidence.
