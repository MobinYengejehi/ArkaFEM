# ArkaFEM / PROMPT 02A — Material Data Registry and Constitutive Properties

**این فایل فقط یک واحد کاری است.** فقط با دستور صریح کاربر اجرا شود. مبنا: آخرین **ZIP کامل ArkaFEM** و تمامی فایل‌های `00_READ_FIRST`, `CONTRACTS`, `REFERENCES`. تاریخچه و کدهای مرحله قبل را حفظ کن. اگر ZIP ورودی موجود نیست، ادامه را از روی حدس نساز.

**در تمام مراحل الزامی:** MATLAB R2024b+ هدف سازگاری (فقط بعد از آزمون تأیید)، SI، `arka` namespace، sparse، نظام DOF، تفکیک Material/Section/Element، قرارداد عددی Logan، تست منفی، Makefile با دستورات Git، مستندسازی روابط و مثال‌ها، status دوگانه implemented/verified. هیچ کد آینده‌ای را بدون تست runnable نام نبر. قراردادهای Master Prompt را کاملاً اجرا کن.

## هدف این برش
Implement Material registry with `linearIsotropic` E,nu,rho,alpha, derived G plus steel/concrete/aluminum/rebar/generic classification metadata; do not imply nonlinearity.

## تسک‌های دقیق اجرایی
1. Implement Material registry with `linearIsotropic` E,nu,rho,alpha, derived G plus steel/concrete/aluminum/rebar/generic classification metadata; do not imply nonlinearity.
2. Add query/list/clone API, model revision propagation, unique references and coherent serialization; `E/nu/G` consistency logic and explicit alpha default.
3. Document mass density vs weight density; no hidden 9.81 self-weight.

## حداقل آزمون پذیرش
1. G=E/(2*(1+nu)) benchmark, inputs E>0, rho>=0,-1<nu<0.5, missing/duplicate IDs and duplicate reference handling.
2. Material metadata must not silently change elastic constitutive behavior.
