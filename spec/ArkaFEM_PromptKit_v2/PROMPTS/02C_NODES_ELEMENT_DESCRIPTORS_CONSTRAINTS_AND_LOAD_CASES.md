**این فایل فقط یک واحد کاری است.** فقط با دستور صریح کاربر اجرا شود. مبنا: آخرین **ZIP کامل ArkaFEM** و تمامی فایل‌های `00_READ_FIRST`, `CONTRACTS`, `REFERENCES`. تاریخچه و کدهای مرحله قبل را حفظ کن. اگر ZIP ورودی موجود نیست، ادامه را از روی حدس نساز.

## هدف این برش
Define unified model descriptors for element family, connectivity, section/material refs, load cases, nodal forces and known DOF displacements with explicit coordinate reference.

## تسک‌های دقیق اجرایی
1. Define unified model descriptors for element family, connectivity, section/material refs, load cases, nodal forces and known DOF displacements with explicit coordinate reference.
2. Build compiler preflight: validate node/member refs, family DOFs, restraint conflict, unused DOFs, section adequacy and model Revision.
3. Lock outward API names and compatibility migration note; no unnecessary fixed universal 6 DOFs at every truss node.

## حداقل آزمون پذیرش
1. Tests for duplicate element, missing node/section, conflicting boundary conditions, wrong force vector length and isolated active DOFs.
2. Show a preliminary model with material and section declarations, but mark solve methods planned until next prompt.
