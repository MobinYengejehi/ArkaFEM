# ArkaFEM / PROMPT 02D — Sparse Assembly and Linear Solver Core

**این فایل فقط یک واحد کاری است.** فقط با دستور صریح کاربر اجرا شود. مبنا: آخرین **ZIP کامل ArkaFEM** و تمامی فایل‌های `00_READ_FIRST`, `CONTRACTS`, `REFERENCES`. تاریخچه و کدهای مرحله قبل را حفظ کن. اگر ZIP ورودی موجود نیست، ادامه را از روی حدس نساز.

**در تمام مراحل الزامی:** MATLAB R2024b+ هدف سازگاری (فقط بعد از آزمون تأیید)، SI، `arka` namespace، sparse، نظام DOF، تفکیک Material/Section/Element، قرارداد عددی Logan، تست منفی، Makefile با دستورات Git، مستندسازی روابط و مثال‌ها، status دوگانه implemented/verified. هیچ کد آینده‌ای را بدون تست runnable نام نبر. قراردادهای Master Prompt را کاملاً اجرا کن.

## هدف این برش
Implement pure element-independent sparse assembly from index triplets plus free/known DOF partition and linear-static solver with reactions and diagnostics.

## تسک‌های دقیق اجرایی
1. Implement pure element-independent sparse assembly from index triplets plus free/known DOF partition and linear-static solver with reactions and diagnostics.
2. Provide interface for element kernels without implementing fake frame stiffness; connect to manually assembled matrices/synthetic element triplets.
3. Guard K symmetry for compatible cases, nonfinite, rank deficiencies, ill-conditioning and model revision cache.

## حداقل آزمون پذیرش
1. Reproduce manual spring chain via assembled synthetic matrices, multiple contributors to same sparse entry and nonzero prescribed displacement.
2. Negative: singular rigid-body mode, contradictory DOFs, invalid indexes, NaN and inconsistent matrix sizes.
