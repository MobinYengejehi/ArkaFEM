# ArkaFEM / PROMPT 03A — Spring and Axial Bar Elements

**این فایل فقط یک واحد کاری است.** فقط با دستور صریح کاربر اجرا شود. مبنا: آخرین **ZIP کامل ArkaFEM** و تمامی فایل‌های `00_READ_FIRST`, `CONTRACTS`, `REFERENCES`. تاریخچه و کدهای مرحله قبل را حفظ کن. اگر ZIP ورودی موجود نیست، ادامه را از روی حدس نساز.

**در تمام مراحل الزامی:** MATLAB R2024b+ هدف سازگاری (فقط بعد از آزمون تأیید)، SI، `arka` namespace، sparse، نظام DOF، تفکیک Material/Section/Element، قرارداد عددی Logan، تست منفی، Makefile با دستورات Git، مستندسازی روابط و مثال‌ها، status دوگانه implemented/verified. هیچ کد آینده‌ای را بدون تست runnable نام نبر. قراردادهای Master Prompt را کاملاً اجرا کن.

## هدف این برش
Implement 1D spring and 1D axial bar kernels with stiffness/local DOF, transformation/recovery, density-appropriate mass only if specifically implemented.

## تسک‌های دقیق اجرایی
1. Implement 1D spring and 1D axial bar kernels with stiffness/local DOF, transformation/recovery, density-appropriate mass only if specifically implemented.
2. Create model registration and solve path for genuine elements using Stage 02 compiler/assembly; no manually hardcoded global K in production API.
3. Respect `F=AE/L` axial stiffness, positive tension, connectivity reversal and prescribed support motion.

## حداقل آزمون پذیرش
1. Spring k=1000 N/m 2-node; bar E=210e9,A=.002,L=3,F=10000 -> u=7.142857142857e-5m.
2. Bad zero length/negative area/unsupported DOF tests, reaction equilibrium and symmetry.
