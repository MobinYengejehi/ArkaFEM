# ArkaFEM / PROMPT 04B — 3D Frame Elements

**این فایل فقط یک واحد کاری است.** فقط با دستور صریح کاربر اجرا شود. مبنا: آخرین **ZIP کامل ArkaFEM** و تمامی فایل‌های `00_READ_FIRST`, `CONTRACTS`, `REFERENCES`. تاریخچه و کدهای مرحله قبل را حفظ کن. اگر ZIP ورودی موجود نیست، ادامه را از روی حدس نساز.

**در تمام مراحل الزامی:** MATLAB R2024b+ هدف سازگاری (فقط بعد از آزمون تأیید)، SI، `arka` namespace، sparse، نظام DOF، تفکیک Material/Section/Element، قرارداد عددی Logan، تست منفی، Makefile با دستورات Git، مستندسازی روابط و مثال‌ها، status دوگانه implemented/verified. هیچ کد آینده‌ای را بدون تست runnable نام نبر. قراردادهای Master Prompt را کاملاً اجرا کن.

## هدف این برش
Implement 12-DOF 3D frame (axial, biaxial Euler-Bernoulli bending, torsion) with A, Iy, Iz, J, E, G, local axes.

## تسک‌های دقیق اجرایی
1. Implement 12-DOF 3D frame (axial, biaxial Euler-Bernoulli bending, torsion) with A, Iy, Iz, J, E, G, local axes.
2. Ensure 3D local frame definition and transformation match sections and sign conventions, and reactions/end forces are reported.
3. Validate dimensional consistency and mass options remain separate until supported.

## حداقل آزمون پذیرش
1. Cantilever in each local bending plane and pure torsion, rotated orientation, K symmetry/eigen rigid modes, 3D equilibrium.
2. Malformed J/G/I/incompatible DOF tests.
