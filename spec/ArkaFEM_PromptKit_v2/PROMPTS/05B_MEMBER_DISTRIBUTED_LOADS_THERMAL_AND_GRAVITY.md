# ArkaFEM / PROMPT 05B — Member Distributed Loads, Thermal and Gravity

**این فایل فقط یک واحد کاری است.** فقط با دستور صریح کاربر اجرا شود. مبنا: آخرین **ZIP کامل ArkaFEM** و تمامی فایل‌های `00_READ_FIRST`, `CONTRACTS`, `REFERENCES`. تاریخچه و کدهای مرحله قبل را حفظ کن. اگر ZIP ورودی موجود نیست، ادامه را از روی حدس نساز.

**در تمام مراحل الزامی:** MATLAB R2024b+ هدف سازگاری (فقط بعد از آزمون تأیید)، SI، `arka` namespace، sparse، نظام DOF، تفکیک Material/Section/Element، قرارداد عددی Logan، تست منفی، Makefile با دستورات Git، مستندسازی روابط و مثال‌ها، status دوگانه implemented/verified. هیچ کد آینده‌ای را بدون تست runnable نام نبر. قراردادهای Master Prompt را کاملاً اجرا کن.

## هدف این برش
Add uniform/linear distributed frame loads with local/global basis and consistent equivalent nodal loads, and recovery that subtracts equivalent loads.

## تسک‌های دقیق اجرایی
1. Add uniform/linear distributed frame loads with local/global basis and consistent equivalent nodal loads, and recovery that subtracts equivalent loads.
2. Explicit thermal axial load option and self-weight using rho, A and **user supplied gravity vector**, preventing double application.
3. Define load signs and fixed-end force diagrams with distinct solver/recovery conventions.

## حداقل آزمون پذیرش
1. Simply supported uniform beam wL/2 reactions and Mmax=wL²/8; cantilever UDL results; axial thermal fixed-end force; gravity case with/without enable.
2. Negative: shape mismatch, wrong basis, repeated self-weight accident.
