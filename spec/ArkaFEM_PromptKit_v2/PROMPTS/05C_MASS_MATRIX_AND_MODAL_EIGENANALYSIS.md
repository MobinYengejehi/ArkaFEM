# ArkaFEM / PROMPT 05C — Mass Matrix and Modal Eigenanalysis

**این فایل فقط یک واحد کاری است.** فقط با دستور صریح کاربر اجرا شود. مبنا: آخرین **ZIP کامل ArkaFEM** و تمامی فایل‌های `00_READ_FIRST`, `CONTRACTS`, `REFERENCES`. تاریخچه و کدهای مرحله قبل را حفظ کن. اگر ZIP ورودی موجود نیست، ادامه را از روی حدس نساز.

## هدف این برش
Introduce consistent/lumped mass implementation with explicit per-element capability; derive generalized eigenproblem K phi = omega^2 M phi under supports.

## تسک‌های دقیق اجرایی
1. Introduce consistent/lumped mass implementation with explicit per-element capability; derive generalized eigenproblem K phi = omega^2 M phi under supports.
2. Add solver for modes, sort natural frequencies, mass-normalization and rigid mode handling; unit [rad/s] and [Hz] conversions documented.
3. No invented dynamic participation data; document normalization and missing mass checks.

## حداقل آزمون پذیرش
1. 1DOF spring-mass omega=sqrt(k/m); 2DOF modal benchmark; eigen residual, positive mass and orthogonality.
2. Negative: zero/negative mass, unstable/singular models, eigen value filtering.
