# ArkaFEM / PROMPT 06C — Plate Bending Formulation

**این فایل فقط یک واحد کاری است.** فقط با دستور صریح کاربر اجرا شود. مبنا: آخرین **ZIP کامل ArkaFEM** و تمامی فایل‌های `00_READ_FIRST`, `CONTRACTS`, `REFERENCES`. تاریخچه و کدهای مرحله قبل را حفظ کن. اگر ZIP ورودی موجود نیست، ادامه را از روی حدس نساز.

**در تمام مراحل الزامی:** MATLAB R2024b+ هدف سازگاری (فقط بعد از آزمون تأیید)، SI، `arka` namespace، sparse، نظام DOF، تفکیک Material/Section/Element، قرارداد عددی Logan، تست منفی، Makefile با دستورات Git، مستندسازی روابط و مثال‌ها، status دوگانه implemented/verified. هیچ کد آینده‌ای را بدون تست runnable نام نبر. قراردادهای Master Prompt را کاملاً اجرا کن.

## هدف این برش
Select a defensible plate bending formulation (e.g., validated Mindlin-type with shear mitigation), specify nodal DOFs, thickness and integration; implement only proven capability.

## تسک‌های دقیق اجرایی
1. Select a defensible plate bending formulation (e.g., validated Mindlin-type with shear mitigation), specify nodal DOFs, thickness and integration; implement only proven capability.
2. Avoid naive shear-locking-prone implementation or mismatched plate/beam DOFs; create element-specific tests.
3. Separate membrane vs plate bending and explain thickness units.

## حداقل آزمون پذیرش
1. Patch/zero-energy/locking check as applicable, analytical plate benchmark where source verified; no invented PASS.
2. Explicitly document unsupported boundary conditions if incomplete.
