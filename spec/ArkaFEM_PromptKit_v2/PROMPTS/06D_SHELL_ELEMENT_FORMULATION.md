# ArkaFEM / PROMPT 06D — Shell Element Formulation

**این فایل فقط یک واحد کاری است.** فقط با دستور صریح کاربر اجرا شود. مبنا: آخرین **ZIP کامل ArkaFEM** و تمامی فایل‌های `00_READ_FIRST`, `CONTRACTS`, `REFERENCES`. تاریخچه و کدهای مرحله قبل را حفظ کن. اگر ZIP ورودی موجود نیست، ادامه را از روی حدس نساز.

**در تمام مراحل الزامی:** MATLAB R2024b+ هدف سازگاری (فقط بعد از آزمون تأیید)، SI، `arka` namespace، sparse، نظام DOF، تفکیک Material/Section/Element، قرارداد عددی Logan، تست منفی، Makefile با دستورات Git، مستندسازی روابط و مثال‌ها، status دوگانه implemented/verified. هیچ کد آینده‌ای را بدون تست runnable نام نبر. قراردادهای Master Prompt را کاملاً اجرا کن.

## هدف این برش
Combine compatible membrane and bending behavior into shell formulation with documented local axes, drilling DOF treatment, rotations and thickness.

## تسک‌های دقیق اجرایی
1. Combine compatible membrane and bending behavior into shell formulation with documented local axes, drilling DOF treatment, rotations and thickness.
2. Audit rigid-body modes and spurious zero-energy modes; no fake drilling stiffness, and mark experimental if necessary.
3. Ensure Shell cannot be registered as stable until numerical benchmark verification.

## حداقل آزمون پذیرش
1. Curved/flat shell tests with checked references, coordinate orientation, mesh convergence and symmetry.
2. If unavailable, deliver design+partial implementation clearly marked incomplete.
