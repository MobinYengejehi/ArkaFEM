# ArkaFEM / PROMPT 06E — 3D Solid Element and Continuum Validation

**این فایل فقط یک واحد کاری است.** فقط با دستور صریح کاربر اجرا شود. مبنا: آخرین **ZIP کامل ArkaFEM** و تمامی فایل‌های `00_READ_FIRST`, `CONTRACTS`, `REFERENCES`. تاریخچه و کدهای مرحله قبل را حفظ کن. اگر ZIP ورودی موجود نیست، ادامه را از روی حدس نساز.

**در تمام مراحل الزامی:** MATLAB R2024b+ هدف سازگاری (فقط بعد از آزمون تأیید)، SI، `arka` namespace، sparse، نظام DOF، تفکیک Material/Section/Element، قرارداد عددی Logan، تست منفی، Makefile با دستورات Git، مستندسازی روابط و مثال‌ها، status دوگانه implemented/verified. هیچ کد آینده‌ای را بدون تست runnable نام نبر. قراردادهای Master Prompt را کاملاً اجرا کن.

## هدف این برش
Implement first verified 3D solid element, e.g. 8-node brick with constitutive matrix, Jacobian and integration.

## تسک‌های دقیق اجرایی
1. Implement first verified 3D solid element, e.g. 8-node brick with constitutive matrix, Jacobian and integration.
2. Handle element inversion, quadrature, nodal stresses and shared mesh compilation; document mass only when implemented.
3. Revalidate all earlier plane/plate/shell results and release advanced continuum as experimental until full proof.

## حداقل آزمون پذیرش
1. 3D stress patch test, rigid body modes, convergence, mesh sensitivity, determinant positivity.
2. Stable capability and limitations explicit in docs and status.
