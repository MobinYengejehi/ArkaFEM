**این فایل فقط یک واحد کاری است.** فقط با دستور صریح کاربر اجرا شود. مبنا: آخرین **ZIP کامل ArkaFEM** و تمامی فایل‌های `00_READ_FIRST`, `CONTRACTS`, `REFERENCES`. تاریخچه و کدهای مرحله قبل را حفظ کن. اگر ZIP ورودی موجود نیست، ادامه را از روی حدس نساز.

## هدف این برش
Implement geometric stiffness for supported beam/frame formulations from validated sources; ensure force sign, prestress context and offsets.

## تسک‌های دقیق اجرایی
1. Implement geometric stiffness for supported beam/frame formulations from validated sources; ensure force sign, prestress context and offsets.
2. Separate linearized buckling eigenvalue problem from second-order static P-Delta iterative equilibrium; solver requirements explicit.
3. Do not infer nonlinear accuracy from a single eigenvalue.

## حداقل آزمون پذیرش
1. Euler column buckling critical P=pi²EI/(KL)² appropriate end conditions, mesh/element convergence; PDelta benchmark.
2. Failure on compression/instability path must be diagnostic.
