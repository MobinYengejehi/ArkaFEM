# ArkaFEM / PROMPT 07B — Material/Geometric Nonlinear Engine

**این فایل فقط یک واحد کاری است.** فقط با دستور صریح کاربر اجرا شود. مبنا: آخرین **ZIP کامل ArkaFEM** و تمامی فایل‌های `00_READ_FIRST`, `CONTRACTS`, `REFERENCES`. تاریخچه و کدهای مرحله قبل را حفظ کن. اگر ZIP ورودی موجود نیست، ادامه را از روی حدس نساز.

**در تمام مراحل الزامی:** MATLAB R2024b+ هدف سازگاری (فقط بعد از آزمون تأیید)، SI، `arka` namespace، sparse، نظام DOF، تفکیک Material/Section/Element، قرارداد عددی Logan، تست منفی، Makefile با دستورات Git، مستندسازی روابط و مثال‌ها، status دوگانه implemented/verified. هیچ کد آینده‌ای را بدون تست runnable نام نبر. قراردادهای Master Prompt را کاملاً اجرا کن.

## هدف این برش
Design incremental-iterative Newton-Raphson or modified Newton approach with tangent/internal force/residual, load stepping and convergence controls.

## تسک‌های دقیق اجرایی
1. Design incremental-iterative Newton-Raphson or modified Newton approach with tangent/internal force/residual, load stepping and convergence controls.
2. Implement one constitutive law and element family thoroughly rather than unsupported universal nonlinear claims; track plastic hinges/element state only when validated.
3. Define rollback/state commit, line search option and explicit nonconvergence errors.

## حداقل آزمون پذیرش
1. Nonlinear one-DOF or bar plastic benchmark with independent solution, load-step sensitivity and convergence/failure cases.
2. Document added reference beyond Logan where needed.
