# ArkaFEM / PROMPT 07C — Transient Dynamics / Time Integration

**این فایل فقط یک واحد کاری است.** فقط با دستور صریح کاربر اجرا شود. مبنا: آخرین **ZIP کامل ArkaFEM** و تمامی فایل‌های `00_READ_FIRST`, `CONTRACTS`, `REFERENCES`. تاریخچه و کدهای مرحله قبل را حفظ کن. اگر ZIP ورودی موجود نیست، ادامه را از روی حدس نساز.

**در تمام مراحل الزامی:** MATLAB R2024b+ هدف سازگاری (فقط بعد از آزمون تأیید)، SI، `arka` namespace، sparse، نظام DOF، تفکیک Material/Section/Element، قرارداد عددی Logan، تست منفی، Makefile با دستورات Git، مستندسازی روابط و مثال‌ها، status دوگانه implemented/verified. هیچ کد آینده‌ای را بدون تست runnable نام نبر. قراردادهای Master Prompt را کاملاً اجرا کن.

## هدف این برش
Define M,C,K dynamic equation with Newmark-beta (or chosen justified algorithm), initial conditions, time step and excitations; optional damping model documented.

## تسک‌های دقیق اجرایی
1. Define M,C,K dynamic equation with Newmark-beta (or chosen justified algorithm), initial conditions, time step and excitations; optional damping model documented.
2. Implement time integration for validated element families with reproducible time series and explicit units.
3. Separate linear transient from nonlinear history; do not claim earthquake-code compliance or response spectrum if not implemented.

## حداقل آزمون پذیرش
1. Undamped 1DOF oscillator analytic sinusoidal response and energy drift; timestep convergence, damped free vibration.
2. Record unstable integration and bad input diagnostics.
