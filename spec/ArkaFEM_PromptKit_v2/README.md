# ArkaFEM — Prompt Kit v2.0 (Persian)

This is a **complete stage-by-stage prompt and engineering contract pack** for building an open-source MATLAB structural FEM library. It includes **31 executable developer prompts**, initial architecture/numerical contract references, material and cross-section specification, reproducible numerical documentation requirements, Makefile/Git template, QA/progress rules, and handoff templates.

**This ZIP is NOT a finished MATLAB FEM library and does not claim tests were executed.**

Quick start: read `00_READ_FIRST/00_START_HERE_FA.md`, then copy `00_READ_FIRST/03_COPY_PASTE_START.md` to the development agent. Only `01A` is authorized initially.

Main computational reference: Daryl L. Logan, *A First Course in the Finite Element Method*, 6th ed. Commercial SAP2000 is referenced only for publicly documented material/section modeling concepts, with no proprietary source, databases or copyrighted content redistributed.
